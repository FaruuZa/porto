# Portfolio Developer — Omori White Space & Sketchbook Edition

Portofolio software engineer yang bersih, cepat, dan berkarakter, terinspirasi oleh atmosfer seni **Omori** (White Space, sketchy dialogue box, notebook sketchbook paper, dan Black Space psychological horror).

Dibuat dengan **Vite + React + TypeScript + Tailwind CSS**. Tanpa animasi berat, tanpa canvas yang membebani GPU/RAM, dan tanpa tombol-tombol yang membingungkan.

---

## 🚀 Cara Menjalankan di VPS (Port 8000)

Untuk performa maksimal dan bebas buffering:

```bash
# 1. Install dependensi
npm install

# 2. Build proyek untuk produksi (bundling optimal ~100KB)
npm run build

# 3. Jalankan server di port 8000
npm run preview
```

Buka `http://IP_VPS_KAMU:8000` di browsermu.

---

## 🎨 Karakteristik Desain

1. **Omori Hanging Lightbulb**: Sketsa lampu gantung White Space yang dapat diklik di atas halaman.
2. **White Space / Black Space Mode**: Toggle di kanan atas navbar untuk beralih antara tema gelap tinta dan tema terang kertas sketsa.
3. **Omori Dialogue Box**: Kotak dialog monokrom khas Omori untuk perkenalan diri dan status akademik.
4. **Hand-drawn Sketchbook Cards**: Kartu proyek dan keahlian menggunakan border organik bergaya coretan pensil tangan bebas (*hand-drawn doodle*).
5. **Placeholder Icons**: Ikon minimalis yang modular di `src/components/PlaceholderIcon.tsx`.
